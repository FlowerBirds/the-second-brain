# RAG 技术介绍

RAG (Retrieval-Augmented Generation) 是一种结合检索和生成的技术。

## 核心思想

RAG 通过从外部知识库检索相关信息，然后将这些信息作为上下文提供给大型语言模型（LLM），从而生成更准确、更基于事实的回答。

## RAG 的优势

1. **知识时效性**: 可以访问最新的信息，不受模型训练数据限制
2. **可解释性**: 答案可以追溯到具体的源文档
3. **减少幻觉**: 模型主要基于检索到的真实内容生成回答
4. **成本效益**: 无需为每个知识领域微调模型

## RAG 工作流程

1. **文档处理**: 将文档分块并转换为向量
2. **向量存储**: 将向量存入向量数据库
3. **检索**: 根据用户问题检索相关文档块
4. **生成**: 将检索结果作为上下文生成回答
